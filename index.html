チームを追加する

リポジトリの teams.json に1件追加して保存すると、次回の自動更新から表示されます。

{
  "id": "arsenal",
  "name": "Arsenal",
  "shortName": "アーセナル",
  "league": "eng.1",
  "leagueName": "プレミアリーグ",
  "espnTeamId": "359",
  "plTeamId": 1,
  "color": "#ef0107"
}

espnTeamId は ESPN のチームページURLの数字、plTeamId は premierleague.com のクラブIDです。詳しくは README を見てください。
