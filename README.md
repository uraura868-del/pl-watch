# PL Watch ・ ネタバレなし観戦ノート

プレミアリーグを「後から観る」人のためのサイトです。
スタメン・フォーメーション・ベンチ・欠場者だけを表示し、**スコア・得点者・順位は一切取得しません。**

- 表示: `index.html`（PC・スマホ両対応、GitHub Pages で公開）
- データ更新: `scripts/update.py`（GitHub Actions が1時間ごとに自動実行）
- データ元: ESPN（日程・スタメン・スタッツ）、Transfermarkt（選手写真・負傷情報）、プレミアリーグ公式（プロフィール・写真の予備）、Wikidata（経歴）、YouTube（動画）
- 選手写真は OpenCV の顔検出で顔を中心に正方形に切り出し、`data/photos/` に保存して表示します（`requirements.txt` のライブラリが必要。無い環境では元の写真URLをそのまま使います）

## 画面の使い方

画面下（PC では見出しの下）のメニューで切り替えます。

| メニュー | 内容 |
|---|---|
| ホーム | チームごとの一覧。最新の試合 → 今後の日程 → これまでの試合。タブでチームを切り替え |
| 日程 | 全チームの試合を日付順に。試合を押すとその試合の詳細が直接開きます（お気に入り、または「観た」記録のあるチームはロックが効きます） |
| 記録 | 「観た」にした試合の集計。今季の試合数・時間（1試合2時間で計算）、月ごと、チーム別、大会別、連続週、よく観た相手など。ログイン中はアカウントに保存されます |
| 設定 | ロック、表示のカスタマイズ、ホーム画面に追加、カレンダー登録、ログイン。観た記録は「表示中のチームだけ」と「すべて」のリセットがあり、すべて消す前には注意ダイアログで「理解しました」にチェックが必要です |

| 場所 | 意味 |
|---|---|
| 次に観る試合 | まだ「観た」にしていない一番古い試合。スタメン・ベンチ・欠場者が見られます |
| その後の試合 | ロック中。上の試合を「観た」にすると順に解放されます |
| 今後の日程 | まだ始まっていない試合。キックオフ約1時間前からスタメンが出ます |
| 観た試合 | 「観た」にした試合。いつでも見返せます |
| ⚙ 設定 | ロックのオン/オフ、観た記録のリセット |
| 選手の写真をタップ | 年齢・国籍・身長・加入日などのプロフィール、観た試合の範囲での出場状況（先発/ベンチ/メンバー外の回数）、所属クラブの経歴（Wikidata、生年月日で本人を照合）。ゴール数などの成績は出しません |

| スタッツのボタン | 「ハーフタイム時」「試合終了時」の2つ。押すまで隠れています。シュート・枠内・コーナー・ファウル・カードなどを両チーム並べて表示。得点・PK・セーブ数は含めず、シュート数はゴールを除いた数です。ボール支配率やパス数は試合終了時のみ |

| 結果を表示 | 確認ダイアログの後にスコア・得点者・退場者を表示。結果は `data/<チーム>/results/` に分けて保存され、ボタンを押すまでブラウザは読み込みません |
| 選手詳細のプレー動画 | YouTube API キーを設定すると、選手ごとに「skills」動画を最大3本サイト内で再生できます。未設定でも「YouTube で探す」リンクは出ます |
| 相手チームの選手 | 観る試合のスタメン・ベンチに入った選手は、プロフィール・経歴・動画が自チームと同じように出ます（`data/opponents/` にチーム横断で保存）。今季の出場回数だけは相手側では出ません |

| ログイン（Google） | 右上の「ログイン」。観た記録・ロック・表示設定が Google アカウントに保存され、PC とスマホで同期されます。ログインしなくても端末保存で使えます |
| 表示のカスタマイズ | 設定で「結果ボタン」「スタッツ」「プレー動画」「ピッチ図の選手名」を個別に非表示にできます |

一覧画面の「✓ 観た」「ここまで観た」「戻す」ボタンで、試合を開かずに記録を変えられます。

### ログインの仕組み（技術メモ）

- Firebase Authentication（Google プロバイダ）と Cloud Firestore を使用。設定値は `assets/firebase-config.js`（公開前提の識別子）
- 保存先は `users/{uid}` の1ドキュメントだけ。セキュリティルールで本人以外は読み書き不可
- 初回ログイン時は端末の「観た」記録とクラウドの記録を和集合で合わせ、設定はクラウド優先
- Firebase 側の設定: Authentication → Sign-in method で Google を有効化、承認済みドメインに公開ドメインを追加、Firestore を作成しルールを設定

## プレー動画のサイト内再生を有効にする（YouTube API キー）

1. https://console.cloud.google.com/ を開き、Google アカウントでログイン
2. 上部のプロジェクト選択から「新しいプロジェクト」を作る（名前は何でも可、例: pl-watch）
3. 左メニュー「APIとサービス → ライブラリ」で **YouTube Data API v3** を検索し「有効にする」
4. 「APIとサービス → 認証情報 → 認証情報を作成 → APIキー」でキーを作る
5. できたキーの「キーを制限」で、API の制限を YouTube Data API v3 だけにしておく（推奨）
6. GitHub のリポジトリで **Settings → Secrets and variables → Actions → New repository secret**
   Name: `YOUTUBE_API_KEY`、Secret: 作ったキー を登録
7. Actions タブで `update-and-deploy` を手動実行（Run workflow）すると動画の取得が始まります

無料枠は1日あたり検索100回分です。選手1人につき月1回しか検索しないので、通常は枠内に収まります。
PC でローカル実行するときは、環境変数 `YOUTUBE_API_KEY` を設定してから `python scripts/update.py` を実行してください。

タイトルに「vs」「goal」「highlights」やスコアらしき数字を含む動画は除外していますが、完全ではありません。

「観た」の記録はブラウザ（localStorage）に保存されます。スマホとPCで別々に記録されます。

### なぜロックするのか

次の試合のスタメンを見ると「あの選手がいない → 前の試合で怪我した？」のように展開が推測できてしまうためです。
気にしない場合は設定でロックをオフにできます。

## 欠場理由について

欠場者は「選手名鑑 − 当日のメンバー」で自動検出し、理由は Transfermarkt の負傷・出場停止ページから毎時取り込みます
（`data/<チーム>/injuries.json` に履歴として溜まり、試合日と照合して表示。よく出る英語の理由は日本語に置き換え）。
自動で付かない・直したい場合は `absences.json` に書くと、そちらが優先されます。

## カップ戦

`teams.json` の `competitions` に書いた大会（ESPN のリーグコード）をすべて取得し、日付順に並べます。
主なコード: `eng.1`（プレミアリーグ）、`uefa.champions`（CL）、`uefa.europa`（EL）、`uefa.europa.conf`（ECL）、`eng.league_cup`（カラバオ杯）、`eng.fa`（FA杯）、`eng.charity`（コミュニティ・シールド）。

## キックオフ通知（カレンダー購読）

`data/<チーム>/fixtures.ics` が毎時生成されます。設定（⚙）に出る URL をカレンダーに「URL で追加」すると日程が入ります。
Google カレンダーは PC の「他のカレンダー ＋ → URL で追加」から。追加したカレンダーの通知を「1時間前」にすると、スタメン公開のころに通知が来ます。
iPhone は設定画面の「iPhone / Mac で登録」から購読できます。結果やスコアは含まれません。

## 欠場理由を手で書く（absences.json）

`absences.json` に書くと、自動取得より優先して表示されます。

```json
{
  "man-utd": [
    { "name": "Mazraoui", "type": "負傷", "reason": "ハムストリング", "from": "2026-10-01", "until": "2026-11-15" },
    { "name": "Bruno Fernandes", "type": "出場停止", "reason": "累積警告" }
  ]
}
```

- `name` は英語表記。姓だけでも一致します
- `from` / `until` は省略可。書くとその期間の試合にだけ適用されます
- 保存して GitHub に push すると、次回の自動更新から反映されます（過去の試合には再生成時のみ反映）

## チームを選ぶ

プレミアリーグ全20チームのデータを毎時更新しています。タブの「＋ チームを選ぶ」で表示するチームをチェックすると、
そのチームだけがタブに出ます（未選択なら全チーム）。ログイン中はこの選択もアカウントに保存されます。

## チームを追加する（teams.json）

```json
{
  "id": "arsenal",
  "name": "Arsenal",
  "shortName": "アーセナル",
  "league": "eng.1",
  "leagueName": "プレミアリーグ",
  "espnTeamId": "359",
  "plTeamId": 1,
  "color": "#ef0107"
}
```

- `espnTeamId`: ESPN のチームページ URL `espn.com/soccer/team/_/id/359/arsenal` の数字
- `plTeamId`: premierleague.com のクラブ ID（主なチーム: Arsenal 1, Aston Villa 2, Chelsea 4, Everton 7, Liverpool 10, Man City 11, Man Utd 12, Newcastle 23, Tottenham 21, West Ham 25）
- `color`: チームカラー（タブやボタンの色に使われます）

## GitHub Pages で公開する手順

1. GitHub に新しいリポジトリを作る（Public 推奨。Private だと Pages に有料プランが必要）
2. リポジトリの **Settings → Pages → Build and deployment → Source** を `GitHub Actions` にする
3. このフォルダを push する。push をきっかけに **Actions** の `update-and-deploy` が走り、公開されます
4. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で見られます（URL は Actions の実行結果にも表示されます）

以降は毎時7分（UTC）にデータ更新と再公開が自動で行われます。費用はかかりません。

うまくいかないときは **Settings → Actions → General → Workflow permissions** が
`Read and write permissions` になっているか確認してください。

## ホーム画面に追加（PWA）

`manifest.json` と `sw.js` により、スマホのホーム画面にアイコン付きで追加してアプリのように開けます。
設定（⚙）の「ホーム画面に追加」に端末ごとの手順が出ます。アイコンは `scripts/make_icons.py` で生成しています。
Service Worker は画面の骨組みだけをキャッシュし、data/ 以下は常にネットワークから取ります。

## PC でローカル表示する

`serve.bat` をダブルクリックすると http://localhost:8787 が開きます
（`index.html` を直接ダブルクリックすると、ブラウザの制限でデータが読み込めません）。

手動でデータを更新するには:

```bash
python scripts/update.py
```

## ネタバレ防止の仕組み（技術メモ）

- `update.py` は取得した JSON から必要な項目だけを手で詰め直す「ホワイトリスト方式」
- 書き出す直前に `score` `winner` `goals` などの禁止ワードが含まれていないか検査し、含まれていれば書き込みを中止
- 交代が実際に行われたか・何分に行われたかも保存しない（展開の推測を防ぐため）
- 外部サイトへのリンクは置かない
